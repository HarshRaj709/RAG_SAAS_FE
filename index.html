How it works

From raw files to a production chatbot in four steps.

1. Upload

Drop PDFs, DOCX, MD or TXT files. We validate type and size in the browser.

2. Process

Recursive text splitting, embeddings and Qdrant indexing — watch live status.

3. Create bot

Link one or more knowledge bases, get a slug and a one-time API key.

4. Integrate

POST answers with session memory of the last 10 messages.

FAQ
Quick answers before you dive in.

  
What file types are supported?
PDF, DOCX, Markdown and TXT. 50 MB per file by default (configurable).

  
What happens if I lose my bot API key?
We store only a hash, so it can't be recovered. Regenerate a new key from the bot page.

  
How does session memory work?
Pass a UUID session_id with each chat call; the server remembers the last 10 messages.

  
Can I belong to multiple organizations?
Yes — use the org switcher in the topbar. Each org's KBs, bots and members are isolated.
